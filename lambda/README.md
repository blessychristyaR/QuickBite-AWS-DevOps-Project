# Lambda source files

The AWS Lambda functions are deployed in AWS, but their source files have not yet been added to this repository package.

Export the actual deployed code from the AWS Lambda console and add the source files here. Suggested filenames:

- `submit_order.py`
- `process_order.py`
- `get_order_status.py`
- `update_order_status.py`


Do not replace these with invented or empty implementations. Before committing, remove credentials, personal data, and other secrets. Check that the README accurately reflects the code you include.
